# via — link page

one simple page for the via music community: a big "enter via" invitation, plus a few quieter links.

the whole page is one file, `index.html`. the style follows the via master reference — deep ink, gold, cormorant garamond and jost, lowercase prose.

## changing links

you don't need to touch any code. just ask claude in plain words, e.g. "set the join link to my skool page" or "add a link to our new mix".
